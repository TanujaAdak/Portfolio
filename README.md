## ✨ Features & Architecture

- **Dark Editorial Aesthetic**: Curated bespoke color palette (`#17191D` base, `#22252A` surfaces, `#A6D957` chartreuse accent) with strict token-based Vanilla CSS Modules.
- **Two-Column Interactive Hero**:
  - Narrative introduction, dynamic role headlines, and direct CTA actions.
  - Floating engineering profile card with real-time status radar ping, live signal equalizer bars, active pipeline telemetry, and verified metrics.
- **Bento-Grid About Section**: Editorial storytelling highlighting core domains across Machine Learning, Full-Stack engineering, and academic achievements.
- **Featured Projects Showcase**: 3D parallax tilt cards, code preview mockups, tech badges, and direct repository links.
- **Scholarly Research & Certifications**: Dedicated highlights for IEEE-supported preprint research and accredited industry certifications.
- **Accessible & Performant**: Hardware-accelerated 60fps animations, fully responsive layout across desktop/tablet/mobile, and graceful fallback with `prefers-reduced-motion`.

## ⚡ Local Development

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/TanujaAdak/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local dev server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Lint and build for production:**
   ```bash
   npm run lint
   npm run build
   ```
